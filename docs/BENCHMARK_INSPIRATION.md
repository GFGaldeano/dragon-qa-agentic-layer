# Benchmark Research

DRAGON QA Agentic Layer is independently implemented.

Its architecture was informed by technical benchmark research into:

- Agentic QE
- Suitest
- TestZeus Hercules
- Quorvex AI
- Microsoft Playwright MCP

No AGPL source code is incorporated into the DRAGON QA core.

Any future third-party source inclusion must undergo an explicit
license and compatibility review before incorporation.
